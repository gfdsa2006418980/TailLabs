# TL002《蛇貂逃家了》

Vite + TypeScript + Phaser 3 的 one-button endless runner。蛇貂固定在偏左側，世界與障礙往左移動；以單跳、二段跳避開障礙、跳上平台、收集本局金幣，盡可能逃得更遠。

## 啟動與 TL002 專屬驗證

```sh
npm run dev:tl002
npm run test:tl002
npm run build:tl002
npm run preview:tl002
```

- 開發入口 `http://localhost:5174/`；亦可雙擊根目錄的 `啟動 TL002.cmd`。
- 同區網手機可使用開發伺服器顯示的 Network 位址，能否連線仍取決於網路與防火牆。
- 單獨建置輸出 `dist/TL002/`；正式預覽 `http://localhost:4174/`。
- `typecheck:tl002` 使用獨立 `tsconfig.tl002.json`，只涵蓋 TL002 原始碼與設定。
- `test:tl002` 只執行 `tests/runner*.test.mjs`。本輪不執行 TL001 的測試、建置或瀏覽器驗收。
- 完整網站建置仍可使用既有 `npm run build`；TL002 的加入不需要改動發布整個 `dist/` 的 Pages 工作流程。
- TL002 正式路徑為 `/TailLabs/TL002/`，`base: './'` 保留相對資源網址。

## 操作與障礙

- Space、↑、滑鼠左鍵、輕點遊戲區：第一次跳躍；空中再按一次：二段跳。長按不自動連跳。
- 交通錐高 58 px、紙箱高 48 px，單跳可通過；路燈高 148 px，需二段跳越過。
- 平台寬 250 px、高 76 或 100 px；只在從上方下落時接住腳底，可從下方穿過。站穩後恢復兩次跳躍；離開平台邊緣保留 Coyote Time。
- 失去支撐後超過 Coyote Time，視為已用掉地面跳躍，只剩一次空中跳，避免離台後額外多跳一次。
- Escape、開啟選單／排行榜或切離視窗會立即暫停。開始、按「繼續」或選單「返回遊戲」，均先顯示 2（1 秒）→1（1 秒）→START（350 ms），再啟動／恢復世界。倒數不增加時間、速度、距離、分數或金幣；倒數中的跳躍輸入會丟棄，切離視窗會取消倒數。
- 碰撞當下停止世界、生成、距離與金幣拾取；摔倒後 400 ms 顯示總分結算。選「再逃一次」或選單「重新開始」只重設並回到「蛇貂逃家了！」開始畫面，必須再按開始。已收集但尚未抵達 HUD 的金幣會完成動畫；回開始畫面時清除所有舊動畫。

## 節奏門與結算圖

- 節奏門是獨立的操作障礙，沿用 Space／↑／點擊／Tap。跑條未出現或指標仍在灰色安全區時可正常跳躍；綠色開門窗前 0.5 秒為橘紅色太早失敗區，綠色後方至接觸門前也標為橘紅色失敗區。只有指標進入太早失敗區後，提前輸入才會立即跌倒；綠色區段按下開門，不會同時跳躍。顏色區段與實際判定共用同一份時間資料。
- 判定條只顯示色塊與移動指標，不顯示狀態文字或圖示；選單也不放操作說明。判定窗總長採用試玩後的設定：**×1 = 0.75 秒、×2 = 0.5 秒、×3 = 0.4 秒、×4 = 0.3 秒、×5 = 0.2 秒**，倍率之間線性內插，皆以目標時間為中心，前後各一半。每扇門生成時鎖定判定窗，加速途中與暫停恢復都不會改變已生成的門；綠色區段與實際判定共用同一份門資料。可調整 `src/tl002/RunnerGate.ts` 的 `RHYTHM_GATE`。
- 各難度都在預計接觸前 **2 秒**提示，最寬的判定窗仍有 925 ms 預告，其中最前方至少 425 ms 可正常跳躍，再進入 500 ms 的太早失敗區。目標固定在接觸門前 700 ms，即使最晚成功按下，也有至少 325 ms 開門時間。在太早失敗區按下會立即停止世界，結算標題顯示「按太早了，蛇貂跌倒了」。超過判定窗或完全漏按時，先在該扇門記下失敗原因，角色與世界繼續移動，距離、時間、分數與收幣照常累計；直到角色實際碰撞關著的門，才停止遊戲並結算。結算不顯示「錯過開門時機」那一行。記下失敗後再按也不會補開門、跳躍或改寫原因；暫停保留此紀錄，重設新局時清除。一般碰撞仍顯示「被抓回來了」。長按鍵盤不會自動開門。
- 遊玩 10 秒後才可能生成門，前一障礙／平台通過且角色落地後才生成，不連續出門。門通過前不生成下一挑戰，之後另留恢復空間；避開 LEVEL UP 提示。高速時從畫面外提早準備，仍保留完整提示與判定時間。
- 門的位置預先依未來速度曲線積分，確保加速過程中也對齊判定時機。所有計時使用有效模擬時間，暫停、倒數、切離視窗都不消耗判定窗。開門只縮放兩扇門片，使用兩張快取貼圖與原本的物件池，不建立逐幀圖形或額外計時器。
- 結算新增圖片，保留總分／倍率、秒數、金幣、公尺、最佳分數及原有按鈕。暫代圖為現有捲身蛇貂圖，獨立複製至 `TL002/public/assets/results/caught-placeholder.webp`；替換同名檔即可，不需修改程式。圖片固定尺寸並保持比例，避免載入時版面跳動。

## 計分與排行榜

- 畫面原本皇冠的位置，改為星形分數圖示與**本局即時分數**；旁邊顯示速度倍率。最高紀錄只在結算／排行榜呈現。
- 總分為 `floor((距離公尺 + 本局邏輯金幣數) × 當前速度倍率)`，倍率四捨五入至小數兩位，與畫面倍率一致，上限 ×5。例如 `(172 + 25) × 1.50 = 295` 分，小數捨去。
- 金幣拾取時就計入分數，右上角金幣計數仍依原指定，在特效抵達後增加；結算會包含所有已拾取但仍在飛行中的金幣。
- Top 10 依總分降冪，同分依秒數升冪，再依金幣數／距離降冪；每列先顯示分數，下一列為秒數／金幣／公尺。
- 新存檔保留 `score`、`multiplier`、`distance`、`coins`、`elapsedMilliseconds` 等欄位，沿用原本儲存鍵。舊紀錄缺少倍率時，依舊曲線 `min(720, 320 + 140 × ln(1 + seconds / 12))` 推算並補算分數；不刪除舊紀錄。
- 所有查看排行榜的入口皆使用線條獎盃圖示。排行榜內部捲動，標題與關閉按鈕固定可見。

## 音效

TL002 使用獨立的 Web Audio 合成短音效，不載入額外音檔、不依賴 TL001 系統。一般跳躍／二段跳、碰撞、金幣吸入後轉為上彈（拾取約 140 ms 後）各有音效；金幣抵達 HUD 時不重播。啟用減少動態效果時，收幣音效改在即時拾取時播放。

選單有音效開關並儲存偏好。共用一個 AudioContext，最多同時 12 個振盪器，收幣提示限流 45 ms；播放完釋放節點，暫停／靜音會停止現有聲音，重載清理時關閉 Context。不支援或封鎖音訊時仍能遊玩。

## 金幣與指定的五階段回饋

金幣是本局收集數，不延伸商店或養成。開場有安全的平地金幣，障礙上方與平台上方也有金幣；靠近蛇貂 70 px 才會吸入，無法隔著整個畫面收集。

1. **吸到蛇貂身上**：約 140 ms，目標跟隨當下角色身體位置。
2. **從身上往上彈**：約 220 ms，向上彈一小段。
3. **放大與旋轉**：上彈同時逐漸放大至 1.18 倍並旋轉 240 度。
4. **短暫懸停，再飛向右上角**：懸停約 140 ms，接著用 550 ms 曲線飛到實際金幣圖示位置。
5. **數字增加**：抵達後才平滑增加 HUD 數字，圖示短暫縮放回彈。邏輯收集數在拾取當下就已記錄，避免快速結算遺失成績。

整段約 1.05 秒。尺寸依 canvas 的實際比例轉成 CSS 座標；右上角目標在視窗改變或頁面捲動時重新量測。每幀只更新 transform，不逐枚讀取版面幾何。

動畫物件固定 32 個並重用，世界金幣上限 64、待處理拾取事件上限 64。極端超過動畫容量時直接補入計數，保證不丟幣；正常遊玩保留完整動畫。減少動態效果偏好會簡化飛行。排行榜每筆追加可選 `coins` 欄位，舊有只有距離的紀錄仍能讀取。

## 日夜循環

一輪 120 秒，依有效遊玩時間推進；暫停與結算後停止。白天太陽從左側升起、經過高處後往右側落下，接著天空變成紅橘與黃色的黃昏；月亮出現，天空漸暗至近黑的繁星夜空，月亮高掛後西沉；最後天空泛白、太陽再次從左方升起。

天空使用預先繪製的漸層貼圖交叉淡入；房屋、樹叢與地面隨時間染色。星空與日月光暈都先快取；跑動時只改透明度、色調及日月座標。地面與欄杆使用重複貼圖，不在每幀清除重畫背景。

本機開發可用 `?skyTime=50`、`?skyTime=82`、`?skyTime=114` 檢查黃昏、夜晚、黎明。這只偏移美術預覽，不改分數或難度；正式建置不讀取此參數。

## 2026-10-18 金幣吸入起點修正

修正桌面縮放後，金幣特效從地板下方吸入的問題。原本在 Phaser `FIT` 模式使用 `scale.resize`，保留了舊的顯示長寬比例；例如 680×540 邏輯畫布實際顯示為約 903×508，水平與垂直比例分別約 1.327／0.940。特效卻以水平比例計算 Y，造成金幣起點與蛇貂吸附點同時向下偏移。
