# TL003 像素美術流程

戰場與角色使用 [pxl](https://github.com/crsolver/claude-pxl)（MIT，以程式碼描述像素圖）製作，版本鎖在 `package.json` 的 commit `21fee41`。

## 檔案

| 內容 | 路徑 |
| --- | --- |
| 美術原始檔（調色盤、精靈、動畫、場景） | `art/tl003/tl003.px.js` |
| 建置腳本 | `tools/build-tl003-art.mjs` |
| 遊戲讀取的精靈表 | `TL003/public/assets/pixel/tl003.png` |
| 每格座標與動畫時間（自動產生，勿手改） | `src/tl003/generated/sprites.ts` |
| 預覽圖（放大、含格線，git 忽略） | `art/tl003/out/_preview/` |
| 像素風 UI 外框 | `src/tl003/pixel.css` |

修改 `tl003.px.js` 後執行：

```sh
npm run art:tl003
```

## 規格

- 戰場先畫在寬 240 px 的緩衝畫布，再以無平滑放大到螢幕；1 個精靈像素 = 緩衝畫布 1 px = 戰鬥座標 2 單位。
- 透視只改變精靈的縮放，座標換算、觸控與技能命中仍使用原本的 `Projection.ts`。
- 共用 32 色調色盤：輪廓 `#121619`、戰場綠、卡其／木頭、喪屍膚色、血與火、電能青、鋼鐵灰。
- 精靈：3 名傭兵（背影，各有開火影格）、6 種喪屍（4 格走路動畫；行者手繪不對稱）、拒馬（完整／破損）、場景道具、遠方城市天際線。
- 特效：爆炸 6 格、火焰 4 格循環、命中、死亡、電弧、槍口火光；子彈曳光、雷射、技能範圍與準星以像素線繪製。
- 動態：拒馬受擊時短暫晃動，手榴彈爆炸時畫面震動，傭兵待機 1 px 呼吸。
- 沒有對應美術的新敵人種類會先使用行者圖，不會讓畫面當掉。
