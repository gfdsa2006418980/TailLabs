# TL003《無盡防線》：可玩垂直切片

母規格為完整保留的 [TL003-v0.4.md](TL003-v0.4.md)，共 75 節。後續使用者決策記於 [TL003-v0.4-amendments.md](TL003-v0.4-amendments.md)。目前依 2026-10-21 新決策採 **手機優先、直式、敵人從正前方遠處逼近**。

這份文件是實作狀態與操作說明，不縮減或取代母規格。

## 遊玩

```sh
npm ci
npm run dev:tl003
```

開啟 `http://localhost:5175/`，或在 Windows 雙擊 `啟動 TL003.cmd`。

- 傭兵自動攻擊，喪屍由畫面上方遠處出現，逐漸向下方拒馬逼近。
- 擊殺取得戰場資金與戰術經驗；資金可升級、招募、修復或補強拒馬。
- 場上最多三名傭兵。畫面提供步槍手、焚燒兵與電磁兵各一個招募入口。
- 經驗升級會暫停戰鬥，從三張卡片選一張；效果可堆疊。
- 按住技能，拖曳到戰場，放手施放。畫面顯示透視後的實際作用區域，拖出有效戰場放手可取消。
- 亦可點技能再點戰場；鍵盤 1／2／3 選技能、方向鍵移動準星、Enter／Space 施放、Escape 取消準星或暫停。
- 切換分頁或視窗失焦會暫停，需手動繼續。
- 拒馬生命歸零即 Game Over；30 秒完成一個 Wave，20 分鐘觸發 40 Wave 勝利里程碑。

內部戰鬥座標 X 表示距離生成線的進度，Y 表示防線寬度的位置。它們經透視映射後成為畫面由上到下的路線。滑鼠／觸控落點使用反函數回到同一戰鬥座標，因此畫面改成直式時不另建傷害公式。

## 已接通的核心流程

`部署 → Spawn／自動射擊 → 擊殺 → 資金與經驗 → 招募／升級／修復／補強 → 三選一 → 四屬性狀態與主動軍火 → Game Over／勝利 → 計分與天賦點 → 新局`

四屬性分工如下：

| 屬性 | 行為 |
| --- | --- |
| 動能 | 直接傷害；手榴彈仍為動能，爆炸是 Mechanic |
| 火焰 | 聚合 BurnPower／BurnDuration，以 DOT 造成傷害 |
| 生化 | Corrosion 降低有效防禦：`Defense / (1 + CorrosionPower)` |
| 電能 | Shock 提高防禦結算後的受傷倍率，亦作用於 DOT |

暫定 Shock 曲線為 `1 + 0.25 × log2(1 + ShockPower)`，屬於母規格保留給 Simulation 決定的可調參數。普攻、手榴彈、雷射與 DOT 全部進入同一 Calculator。燃燒在施加時快照來源／Tag 加成，再由共用 Calculator 處理防禦與感電，避免每個 Tick 重複套用倍率。

技能急速使用 `BaseCooldown / (1 + Haste / 100)`，沒有硬性最高急速或最短 CD。高頻率的按住連發與 AutoCast 保留在後續內容。

## 第一局平衡

目前預設拒馬 40 HP、步槍基礎傷害 5.2、射擊間隔 1.25 秒。敵人生命隨時間每分鐘 ×1.8，生成頻率 ×1.1，收入 ×1.9；不依玩家永久戰力調整敵人。

128 組分散種子的標準基準測試：不消費、不施放技能；三選一優先動能，否則選第一張。

- 平均存活 **33.67 秒**，範圍 **31.00～37.75 秒**。
- 平均擊殺 **4.99 隻**，範圍 **4～7 隻**。
- 這是基準打法；消費、選擇與技能可以提高表現，沒有腳本死亡或五隻擊殺上限。
- 玩家每分鐘有效 DPS ×2 與完整 20 分鐘經濟／Build 曲線仍待後續長局平衡，不能把目前第一局基準當成完整遊戲驗收。

## 局內／局外資料

局內所有資料僅存在 `DefenseRun` 記憶體。重新整理或重玩後，資金、累計收入、傭兵、等級、敵人、技能冷卻、拒馬生命、經驗與 Build 都會清除，不提供局內讀檔。

本機 mirror key 為 `taillabs.tl003.meta.v1`，只寫入以下 DTO：

```json
{
  "version": 1,
  "TalentPoints": 2,
  "TalentTreeJson": "{\"tier\":1,\"maxNodeLevel\":10,\"nodes\":{},\"unlockedCoreTalents\":[],\"activeCoreTalents\":[]}",
  "HighestClearedWave": 1
}
```

天賦點僅於本局結束時計算，同一 Run 重複渲染結果不會重複發放。得分採母規格公式：`floor(seconds / 30) + floor(log10(TotalEarnedMoney + 1))`，花掉資金不扣分。最高 Wave 僅記錄完整存活過的 Wave。

Cloudflare 目前只預留 `MetaProgressionPort.load/save` 的永久資料介面；尚無部署、登入、雲端同步或衝突合併。既有 TL001／TL002 Worker 與資料庫未更動。無限星盤與核心天賦尚未開放，因此這批天賦點先累積，尚不提供實際永久戰力。
