## 遊玩

```sh
npm ci
npm run dev:tl003
```

開啟 `http://localhost:5175/`，或在 Windows 雙擊 `啟動 TL003.cmd`。

- **部署**：選擇危險等級（通關 20 關後解鎖下一級，喪屍更強、戰功 ×(1 + 等級)）。
- **佈防準備**：連續兩次三選一，先選傭兵、再選投擲物。前 6 次三選一輪流給傭兵和投擲物，選滿 3 名傭兵和 3 個投擲物後才出一般強化卡。
- **關卡**：共 20 關，第 1 關 15 秒，每關 +2 秒，最長 50 秒。倒數結束就停止刷怪，剩下的喪屍會衝鋒。第 4 關起每 3 關出現屍王，第 20 關是超級屍王。
- **休息站**：每關之間依序完成三選一，花錢升級傭兵、補強或修復拒馬。2 秒沒有操作就自動開始下一關。
- **戰鬥**：傭兵自動射擊。按住投擲物拖到戰場上放手施放；也可以點投擲物再點戰場。鍵盤 1／2／3 選投擲物、方向鍵移動準星、Enter／Space 施放、Escape 取消或暫停；休息站按 Enter 開始下一關。
- **加速**：右上角 ×1／×2／×4／×8（開發版或網址加 `?test` 另有 ×16）。
- **自動化**：第一次通過第 10 關後解鎖自動升級，第一次通過第 20 關後解鎖自動選卡（右下角開關）。
- **暫停**：切換分頁或視窗失焦會暫停。暫停選單有傷害與控場回測、減少畫面晃動，以及「放棄這座城市」（已得戰功照樣結算）。
- **結算**：每通過第 n 關得 n 點戰功（全通 210 點）。戰功投入「指揮藍圖」（10 分支 52 節點）；第一次通過第 10、20 關各多開一個核心槽。
- **音效**：全部即時合成。右上角喇叭切換靜音。

# 歷史紀錄（已過時，保留對照）

以下是開發過程中各版本的說明與平衡紀錄，依當時版本撰寫：例如「20 分鐘 40 Wave」、`Burn.ts` 的最強燃燒、3 名傭兵的招募入口、63 節點星圖。這些都已被上方的最終版本取代。

## 已接通的核心流程（v0.4 初版）

`部署 → Spawn／自動射擊（各自射程） → 擊殺 → 資金與經驗 → 升級／修復／補強 → 三選一（招募傭兵、取得技能、彈藥與加成） → 六屬性狀態與主動軍火 → Game Over／勝利 → 計分與戰功 → 指揮星圖投資／偵察／晉階 → 帶入永久效果的新局`

2026-10-23 起改為六屬性（見 [TL003-v0.4-amendments.md](TL003-v0.4-amendments.md)）；下表是改版前的四屬性分工，保留作為對照：

| 屬性 | 行為 |
| --- | --- |
| 動能 | 直接傷害；手榴彈仍為動能，爆炸是 Mechanic |
| 火焰 | 單份最強 BurnPower／BurnDuration；較弱或同強度命中續時並疊易燃、加速燃盡 |
| 生化 | Corrosion 降低有效防禦：`Defense / (1 + CorrosionPower)` |
| 電能 | Shock 提高防禦結算後的受傷倍率，亦作用於 DOT |

暫定 Shock 曲線為 `1 + 0.25 × log2(1 + ShockPower)`，屬於母規格保留給 Simulation 決定的可調參數。普攻、手榴彈、雷射與 DOT 全部進入同一 Calculator。燃燒在施加時快照來源／Tag 加成，再由共用 Calculator 處理防禦與感電，避免每個 Tick 重複套用倍率。

依最新燃燒決策，首次點燃立即掛上完整基礎 DOT，更強的燃燒可立即覆蓋；較弱或同強度命中僅刷新持續時間並增加易燃。時間刷新為原剩餘與新時長的較大值，不直接相加。易燃每層暫定燒快 25%、最多 12 層，同時加速每秒傷害與剩餘時間消耗；更強 DOT 覆蓋時保留易燃，完全燒完才全部清除。例：100 DPS、剩 4 秒，易燃 2 層會以 150 DPS 在約 2.67 秒內燃盡原本 400 傷害；若後續命中續時，則依刷新後的剩餘時間繼續燃燒。

焚燒兵、曳光燃燒彈與燃燒瓶共用這份最強狀態。燃燒瓶接觸立即點燃、火圈內每秒重新施加一次，每次提供 3 秒基礎燃燒時間；火圈持續 6 秒，敵人離開後仍會燃燒至剩餘時間用完。重疊火圈增加易燃，不另加獨立地面 DOT。燃燒中的敵人上方會顯示橘色加速倍率。

技能急速使用 `BaseCooldown / (1 + Haste / 100)`，沒有硬性最高急速或最短 CD。高頻率的按住連發與 AutoCast 保留在後續內容。

## 局內平衡

所有可調數值集中在 `src/tl003/Balance.ts`，由主動玩法 bot（`tools/tl003-balance.mjs`）驗收。

### 2026-10-22 第四次調整：拆掉後期必勝機制、火焰成長砍半

指揮星圖 2.0 上線後量測發現：一撐過第 2～3 隻屍王就必定守滿 20 分鐘（零天賦火焰流 24 局有 2～3 局直接通關），首通落在第 3～8 局。逐項對照後找出四個不吃敵人血量的必勝來源，並依使用者指示把火焰流傷害成長砍半。

| 項目 | 前值 | 新值 |
| --- | --- | --- |
| 易燃層數 | 無上限（後期 100～360 層、燒快 ×25～×90） | 最多 12 層（燒快 ×4） |
| 延燒（質變） | 火區以原燃燒強度點燃所有人，敵群內無限連鎖 | 只點燃尚未著火的敵人，強度為死者燃燒的 40% |
| 手榴彈擊退 | 每次 40px，冷卻縮短後可把屍王與敵群壓在畫面外 | 屍王只退 1/4；不會被推出道路（x<0 無法瞄準） |
| 同類狀態卡 | 每張各自施加一次 | 同一次命中合併為一次施加（強度相加）；裝「千層烈焰」時燃燒仍逐張疊層 |
| 一般卡強度 | `max(0.12, 1.15 × 0.95^(Lv−1))` | Lv3 以前全額（前 2 張），之後 `max(0.04, 1.15 × 0.92^(Lv−3))` |
| 焚燒兵每級成長 | +13% | +6.5%（使用者決定砍半）；基礎傷害 3.5 → 4.5 保住開局 |
| 曳光燃燒彈／高濃度燃料／持久燃劑 | 4／+45%／+30% | 2／+22.5%／+15%（砍半） |

結果（5 組種子中位數，首次守滿 20 分鐘）：動能第 11 局（1.77 小時）、火焰第 12 局（1.91 小時）、經濟第 10 局（1.73 小時）；零天賦首局三流派都不會通關，中位數 146～147 秒。舊版（第一批卡池前）為第 9～20 局，曲線形狀恢復為逐局延長而非斷崖。

### 驗收結果（`npm run test:tl003` 內的 `tl003-balance.test.mjs`）

主動 bot：每 0.25 秒對最靠近拒馬的敵人施放所有就緒技能；以「增加 DPS ÷ 花費」挑選升級或招募，買不起最佳選項時存錢；拒馬受威脅才修復／補強。三選一分動能、火焰、經濟三種偏好。
