# TL003《無盡防線》：可玩垂直切片

母規格為完整保留的 [TL003-v0.4.md](TL003-v0.4.md)，共 75 節。後續使用者決策記於 [TL003-v0.4-amendments.md](TL003-v0.4-amendments.md)。目前依 2026-10-21 新決策採 **手機優先、直式、敵人從正前方遠處逼近**。

這份文件是實作狀態與操作說明，不縮減或取代母規格。

## 遊玩

```sh
npm ci
npm run dev:tl003
```

開啟 `http://localhost:5175/`，或在 Windows 雙擊 `啟動 TL003.cmd`。

- 傭兵自動攻擊，喪屍由畫面上方遠處出現，逐漸向下方拒馬逼近。
- 擊殺取得戰場資金與戰術經驗；資金可升級、招募、修復或補強拒馬。
- 場上最多三名傭兵。畫面提供步槍手、焚燒兵與電磁兵各一個招募入口。
- 經驗升級會暫停戰鬥，從三張卡片選一張；效果可堆疊。
- 按住技能，拖曳到戰場，放手施放。畫面顯示透視後的實際作用區域，拖出有效戰場放手可取消。
- 亦可點技能再點戰場；鍵盤 1／2／3 選技能、方向鍵移動準星、Enter／Space 施放、Escape 取消準星或暫停。
- 切換分頁或視窗失焦會暫停，需手動繼續。
- 拒馬生命歸零即 Game Over；30 秒完成一個 Wave，20 分鐘觸發 40 Wave 勝利里程碑。
- 結算後進入天賦星盤，或從部署畫面開啟；投資永久成長後，可直接部署下一局。

## 已接通的核心流程

`部署 → Spawn／自動射擊 → 擊殺 → 資金與經驗 → 招募／升級／修復／補強 → 三選一 → 四屬性狀態與主動軍火 → Game Over／勝利 → 計分與天賦點 → 星盤投資／探索／突破 → 帶入永久效果的新局`

四屬性分工如下：

| 屬性 | 行為 |
| --- | --- |
| 動能 | 直接傷害；手榴彈仍為動能，爆炸是 Mechanic |
| 火焰 | 單份最強 BurnPower／BurnDuration；較弱或同強度命中續時並疊易燃、加速燃盡 |
| 生化 | Corrosion 降低有效防禦：`Defense / (1 + CorrosionPower)` |
| 電能 | Shock 提高防禦結算後的受傷倍率，亦作用於 DOT |

暫定 Shock 曲線為 `1 + 0.25 × log2(1 + ShockPower)`，屬於母規格保留給 Simulation 決定的可調參數。普攻、手榴彈、雷射與 DOT 全部進入同一 Calculator。燃燒在施加時快照來源／Tag 加成，再由共用 Calculator 處理防禦與感電，避免每個 Tick 重複套用倍率。

依最新燃燒決策，首次點燃立即掛上完整基礎 DOT，更強的燃燒可立即覆蓋；較弱或同強度命中僅刷新持續時間並增加易燃。時間刷新為原剩餘與新時長的較大值，不直接相加。易燃每層暫定燒快 25%，同時加速每秒傷害與剩餘時間消耗；更強 DOT 覆蓋時保留易燃，完全燒完才全部清除。例：100 DPS、剩 4 秒，易燃 2 層會以 150 DPS 在約 2.67 秒內燃盡原本 400 傷害；若後續命中續時，則依刷新後的剩餘時間繼續燃燒。

焚燒兵、曳光燃燒彈與燃燒瓶共用這份最強狀態。燃燒瓶接觸立即點燃、火圈內每秒重新施加一次，每次提供 3 秒基礎燃燒時間；火圈持續 6 秒，敵人離開後仍會燃燒至剩餘時間用完。重疊火圈增加易燃，不另加獨立地面 DOT。燃燒中的敵人上方會顯示橘色加速倍率。

技能急速使用 `BaseCooldown / (1 + Haste / 100)`，沒有硬性最高急速或最短 CD。高頻率的按住連發與 AutoCast 保留在後續內容。

## 第一局平衡

零天賦時預設拒馬 40 HP、步槍基礎傷害 5.2、射擊間隔 1.25 秒。敵人生命隨時間每分鐘 ×1.8，收入 ×1.9；生成頻率依最新補充決策改為原成長速度的 3 倍，即 `1.1 ^ (3 × Minutes)`、每分鐘約 ×1.331。不依玩家永久戰力調整敵人。

開場基礎間隔仍為前 12 秒 3 秒、之後 1.8 秒，再除以頻率倍率。後期可於單一模擬步長補足多次生成，避免刷怪頻率受 60 Hz 限制。

128 組分散種子的標準基準測試：不消費、不施放技能；三選一優先動能，否則選第一張。

- 平均存活 **33.18 秒**，範圍 **30.07～36.80 秒**。
- 平均擊殺 **4.95 隻**，範圍 **4～6 隻**。
- 這是基準打法；消費、選擇與技能可以提高表現，沒有腳本死亡或五隻擊殺上限。
- 玩家每分鐘有效 DPS ×2 與完整 20 分鐘經濟／Build 曲線仍待後續長局平衡，不能把目前第一局基準當成完整遊戲驗收。

## 局內／局外資料

局內所有資料僅存在 `DefenseRun` 記憶體。重新整理或重玩後，資金、累計收入、傭兵、等級、敵人、技能冷卻、拒馬生命、經驗與 Build 都會清除，不提供局內讀檔。

本機 mirror key 為 `taillabs.tl003.meta.v1`，只寫入以下 DTO：

```json
{
  "version": 1,
  "TalentPoints": 2,
  "TalentTreeJson": "{\"tier\":1,\"maxNodeLevel\":10,\"nodes\":{},\"unlockedCoreTalents\":[],\"activeCoreTalents\":[]}",
  "HighestClearedWave": 1
}
```

天賦點僅於本局結束時計算，同一 Run 重複渲染結果不會重複發放。得分採母規格公式：`floor(seconds / 30) + floor(log10(TotalEarnedMoney + 1))`，花掉資金不扣分。最高 Wave 僅記錄完整存活過的 Wave。

Cloudflare 目前只預留 `MetaProgressionPort.load/save` 的永久資料介面；尚無部署、登入、雲端同步或衝突合併。既有 TL001／TL002 Worker 與資料庫未更動。一般天賦已可投資並提供永久戰力，核心天賦效果仍待後續實作。

- 初始只顯示「傭兵訓練」；投入第一點就揭露動能、防守、經濟三個相鄰節點，不要求點滿十級。後續探索沿連線展開。
- 升級成本暫採 `ceil(1.12 ^ Level)`，第一級 1 點，依目前等級計價。所有加成採 `GrowthRate ^ Level`。
- 任一已投資節點達到本階上限，即可免費突破：Tier +1、所有節點上限 +10，保留等級與未花點數。此為第一版可調突破條件，母規格原文不改寫。
- `10/10 → 10/20 → 20/30…` 可持續成長；沒有新增重置、第二永久貨幣或固定最終 Tier。
- 傭兵傷害、屬性傷害、主動技能與經濟效果使用原有 Tag Calculator 的 More 乘區；生命、攻速與急速在開局套用。
- 每局取得一份獨立效果快照。戰鬥、暫停與三選一期間不能購買或突破；其他分頁的局外變動也不會改寫當局戰力。
- 購買、突破與結算使用同一份永久 DTO；修改前重讀 mirror，避免兩個本機分頁使用舊餘額覆蓋對方。重新整理保留天賦，當局仍放棄。
