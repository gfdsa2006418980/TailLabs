# TL001《誰複製了500隻蛇貂》

專案：labs / TailLabs，2026-10-17 初始化。

## 目前範圍

以可部署到 GitHub Pages 的單頁 Web 遊戲為基礎，使用 Vite + TypeScript + Phaser 3 與其 Matter.js 整合。當前先用測試圓球驗證操作、落下、平台碰撞與堆疊。

第一版預留 `NEXT` 外框並標示「待接入」，尚未實作正式抽選與預覽。計數是測試圓球放下次數，尚未代表得分、成功或勝敗判定。

## 已確認的本次手感修正

| 次序 | 使用者決定 | 最終實作 |
| --- | --- | --- |
| 1 | 希望約 3 秒後有黏性，避免持續滾走 | 由下一項修正其時間語意 |
| 2 | 3 秒後開始減速，直到停止後才凍結 | 接觸後 3 秒開始逐漸降低平移與角速度，停穩約 0.45 秒後設為固定剛體 |
| 3 | 每個圓球被碰撞時有輕微假彈性 | 僅變形顯示容器；碰撞時沿受力方向壓縮並橫向鼓起，再經逐漸減弱的回彈還原 |

「3 秒」目前從首次接觸魔法陣、底部或另一顆已放下圓球開始算，這是本次原型採用的起算點；使用者尚未另外指定從放手或生成時起算。離開接觸時不施加黏性減速，也不在空中固定，重新接觸後需再次滿足連續停穩時間。

目前參數：減速延遲 3000 ms、減速時間常數 450 ms、平移速度門檻 0.06 px／物理步、角速度門檻 0.003 rad／物理步、連續停穩 450 ms；可在 `src/systems/StickinessSystem.ts` 集中調整。這些數值屬原型參數，等待實際遊玩調整。

柔軟回彈最大橫向伸展約 14%，固定物件的幅度為其 65%；壓縮與伸展維持近似面積，四段回彈共約 415 ms，100 ms 內不重複觸發。固定後的位置與角度保持不變，仍保留外觀回彈。
